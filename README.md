# Catholic Latin Prayer Companion

A personal, independent, mobile-first web app for learning traditional Catholic prayers in Ecclesiastical Latin.

## Version 1 goals

- Prayer library with Latin and English side-by-side, a visible column divider, and line-by-line pronunciation guidance
- Links to verified human-spoken prayer audio, distinguishing spoken and chanted recordings and avoiding synthetic substitutes
- Memorization mode to hide and reveal phrases
- Latin/English flashcards
- Learning progress saved locally in the browser

## Technical direction

- React + TypeScript + Vite
- Responsive and accessible design, inspired by traditional prayer books (navy, ivory, muted gold)
- Static hosting on GitHub Pages
- No backend, account registration, paid API, or required subscription
- No connections to business repositories, brands, systems, or development roadmaps

## Content quality

Review prayer texts, translations, pronunciation, and recording links against reliable sources before publication. Do not fabricate audio links or claim a recording is human-spoken unless verified. Do not copy third-party audio into the repository without permission.
